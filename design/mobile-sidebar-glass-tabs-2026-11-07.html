侧边栏结构

从左侧滑出，宽 288 / 320（90%）；主界面整体右移，右侧留 32px 缝隙。
  • 顶部：Agent 名（用户自定义）+ 一句话状态，右上关闭
  • 分区：旁聊（标题 + 长按重命名 + 数量），无「选项卡」
  • 行内容：会话名 / 最近一句 / 时间；进行中带绿点
  • 列表末尾固定 ＋ 新建旁聊（虚线卡）
  • 底部 dock：设置齿轮 · 搜索旁聊 · 新建旁聊
BEHAVIOR

迁移与交互

设置不再占底栏一格；旁聊与主会话完全解耦。
  • 底栏 对话 / 日程 / 目标 / 资料库，设置 → 侧边栏左下角
  • 输入框 46px 高、左右 8px 近满宽；右上邀请按钮移除
  • 抽屉滑入 240ms cubic-bezier(.22,.61,.36,1)，遮罩 200ms
  • 未读旁聊在列表绿点 + 列表右侧时间，不做红点轰炸
  • 新建旁聊默认命名「未命名旁聊」，首条消息后自动改标题
  • 旁聊上限、删除/归档放在长按菜单（设计稿不展开）

说明：本页为静态设计稿，用 MiSans / 手机壳 320×690 还原；玻璃参数与尺寸可直接映射到 Flutter（BackdropFilter + ClipRRect）。 旁聊数据归属与主会话同级，仅多一个 thread 维度，互不覆盖历史。
