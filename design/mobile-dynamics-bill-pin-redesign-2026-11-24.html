磨砂玻璃视觉规格（对齐参照图第二档）

不是液态玻璃（无强镜面高光边），是雾面磨砂：玻璃后内容大面积虚化成雾，仅隐约透出色块。
玻璃底深色 rgba(27,27,31,.45) / 浅色 rgba(255,255,255,.48) —— 透明度拉高，玻璃更通透，仅卡片有磨砂感
模糊blur(26px) saturate(1.3~1.35)：大模糊雾面；Flutter 落地用 BackdropFilter(ImageFilter.blur(sigma 26)) + ClipRRect
描边深色 rgba(255,255,255,.12) / 浅色 rgba(255,255,255,.60) 细白描边 + inset 0 1px 顶部 1px 微高光
投影深色 0 12px 32px rgba(0,0,0,.38) / 浅色 0 12px 28px rgba(30,41,59,.18)，让玻璃卡浮出背景
背景手机屏保持纯色深底（深色黑 #121214）——只有卡片有磨砂玻璃感，背景不加任何壁纸/渐变；玻璃透出底色与相邻内容
浅色对比正文 / 次要文字加深一档（primary #14161C / secondary #5E6470 / muted #8B919E），白玻璃卡靠描边 + 阴影勾轮廓
应用范围槽位卡、聚合卡、小结块、明细卡、筛选 chips、AppBar、底部 tab 全部玻璃化；取件码反白块、按钮等实心元素保持不变
