NextBot · Travel / UI Redesign · 2026.10.25

行程 · 票根册

现在的往期是一排等宽卡片，没有主次，也没有「收藏」的感觉。这一版把它做成一本旅行档案：时间有脊椎，票有纸感，照片有落位。未来的行程是屏幕，过去的行程是纸。

深色 / 暖色双主题 往期 · 进行中 · 即将出发 HarmonyOS Sans SC 基于 travel_plan_archive.dart
01

为什么现在没感觉

对照现有实现，不是审美偏好
01等宽等高

Wrap 网格里全是 236–420px 的同构卡，眼睛没有落点，像设置列表。

02主次颠倒

第一行是「ITINERARY PASS · NB-xxxx」，目的地和「此地」同字号，票据号抢了主视觉。

03不像票

撕线是一条直线，打孔是贴在边上的圆，没有印章、纸纹、条码关系，只是「右边缘」。

04场景缺位

纯色底 + 卡片悬浮；往期只靠 opacity .82 区分，没有「已经走完」的仪式感。

05素材浪费

_PlanSummary.coverImage 已经解析，列表卡从未使用。目的地照片是现成的场景。

02

设计主张

一句话记住这版
过去的行程是纸，
未来的行程是光。

往期做成可以翻的票根册：纸、撕线、缺口、印章、照片。进行中和即将出发保留电子登机牌：暗面、霓虹、实时进度。两种材质不是风格混搭，而是时间语义——已发生的变成实体收藏，未发生的还在屏幕里发亮。

P1 / HIERARCHY

有主次

最新一段用 2.8:1 大票，其余两列紧凑票。先看见「刚从哪回来」，再扫「还去过哪」。

P2 / MATERIAL

有实体

米白纸、6% 噪点、内侧高光、外侧深影、±0.5° 微倾。先相信它是一张票，再读信息。

P3 / TIME

有时间

年 → 月 → 票的时间脊椎，月份上是挖出来的孔。旅行不再是列表，而是一条可以回看的路。

01照片窗 96–158px

直接用 coverImage，去饱和 + 轻微棕调，像印在纸上的照片。无图时用目的地首字 + 等高线兜底。

02目的地唯一主视觉

27–32px / 750。票据号退到 7px 微行，不再和地名抢第一眼。

03字段行

日期 / 预算 / 站点三段式，标签小一号、数值等宽对齐，扫读不跳行。

04真撕线

1.5px 虚线 + 上下 16px 半圆缺口；缺口用页面底色挖洞，票才有厚度。

05跨线章

58px 圆章中心压在撕线上，旋转 -12°，mix-blend-mode: multiply 吃进纸纹。

06存根联

96–104px：条码 + 票号 + 竖排 ARCHIVE，保留撕下来可以单独收的想象。

07纸感

#F2EBDC 纸底、6% 噪点、1px 内侧高光、外侧深阴影，±0.5° 微倾。

08

动效与落地

不新增接口，复用现有数据
01
入场

按月分组 40ms stagger；票从 -6px / ±1.2° 归位，最后落定在 ±0.5° 的静止倾角。

02
悬停

票身扶正 + 上浮 4px，照片以 0.6s 缓推到 1.03，阴影加深；章不参与位移，保持「盖在纸上」。

03
打开

票身轻抬到 1.02 后淡出，详情页从票的位置展开；返回时落回原位，不重新入场。

04
新归档

复用已有的 _TicketPrintOverlay 出票仪式；行程结束后第一次进往期，在最新票上补盖一枚章。

  • lib/features/chat/travel_plan_archive.dart

    _RailList 改为年/月分组；_TripCard 拆成 _TicketPass / _TicketStub / _StampSeal；新增 _LedgerSpine。

  • lib/features/chat/travel_theme.dart

    新增 TicketPalette：paper / paperEdge / ink / muted / stamp / tape，随 AppThemeVariant 切换。

  • _PlanSummary（同文件）

    coverImage、stopCount、totalCost、startDate 都已存在；段数 / 天数 / 地点数在前端聚合，不需要新接口。

  • 图片

    Image.network + fadeIn + errorBuilder 走等高线兜底；建议按 planId 做内存缓存，避免滚动重复请求。

720单列紧凑票；月份脊椎保留，主票照片窗缩到 96px。
980主票 + 两列次票；本稿基准。
1280两列次票不再拉宽，整页居中留在 980–1020，避免票面变成横幅。
