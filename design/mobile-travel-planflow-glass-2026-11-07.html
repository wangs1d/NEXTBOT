旅游规划 · 单绿泡玻璃流（设计稿 v1）

按你提的三点重构：① 全部信息在卡片内完成（选择 / 填写，不用回主界面打字）；② 一次绿泡跑完整流程（玻璃质感 + 当前卡滑出、下一卡滑入）；③ 景点/酒店卡 1:1 还原参考图（错落照片、推荐率胶囊、绿泡接近满屏），同时删除吃饭地点选择，改为在地图路线上展示沿线高分餐厅 POI。
① 卡片内闭环问题、选项、自由输入全部在绿泡里；选项点选即生效，不再要求用户去主界面回一句。
② 一次绿泡同一条消息内原地换卡：选中 → 当前卡滑出 → 下一卡滑入；顶部常驻已定摘要，进度轨推到下一步。
③ 玻璃 + 错落照片绿泡占满对话区宽度（≈ 屏宽 − 16）；照片三张不等高不等顶，错落排布，不套整齐网格。

六、Flutter 实现规格供后续编码直接对照

玻璃质感BackdropFilter

  • 结构：ClipRRect(26) → BackdropFilter(ImageFilter.blur(28, 28)) → Container（渐变 + 描边 + 内阴影）。
  • 填充：LinearGradient(158°)：mint 13% → 白 5.5% → 白 2.8% → mint 5%。
  • 描边 1px rgba(212,212,216,.20)；顶部内高光 inset 0 1px 0 rgba(255,255,255,.14)。
  • 性能：气泡外RepaintBoundary，气泡内列表滚动区域单独裁切；blur sigma ≤ 28，避免中低端机掉帧。

一次绿泡 · 换卡动效AnimatedSwitcher + AnimatedSize

  • 容器：AnimatedSize(duration: 340ms, curve: Curves.easeOutCubic)，外层 ClipRect。
  • 切换：AnimatedSwitcher(320ms)，入 SlideTransition(Offset(0.12,0)→0) + FadeTransition，出左移 12px + 淡出（160ms）+ ImageFiltered 轻微模糊。
  • 点选反馈：ScaleTransition 0.98→1（60ms，easeOutBack）+ HapticFeedback.selectionClick()；选中后 220ms 再触发换卡。
  • 进度轨：4 段 3px，完成 mint 实色，当前段 mint→35% 渐变，切换时 300ms 补间。

尺寸与错落照片条

  • 绿泡宽：手机 = 对话区宽 − 16（≈ 屏宽 − 16，接近满屏）；桌面 maxWidth 720。
  • 照片条：Row + 固定宽度百分比 31.5 / 31 / 30，高度 104 / 114 / 92，顶部偏移 +9 / −3 / +16，间距 8，圆角 14。
  • 不用 GridView / 等宽等高，避免「整齐网格」；图片 BoxFit.cover + 本地 MediaDiskCache 预热。
  • 无图走渐变兜底，不放假图；选中照片 1px mint 描边 + 2px 外发光 + ✓ 角标。

数据与改动清单两端同步

  • 删美食：TravelGuideSelectCard 去掉 food 分组、'美食'标签与 selectedFood；服务端 travel.destination-guide 的 cats 只发 view/stay。
  • 删追问：travel-plan-session.ts 的 foodWishlist 追问与文案下线；预算卡「美食」改为「自行安排 · 不计入」或直接隐藏。
  • 推荐率：用真实信号（同目的地被选比例 / 收藏加权）生成，取不到不下发胶囊；字段建议 metrics[{kind:'recommend', label:'50% 人推荐', source}]。
  • 餐厅 POI：地图新增图层，评分 ≥4.5、距路线 ≤800m、营业中，最多 6 个；不参与编排与预算。
  • 两端共用：AgentResultCard 同时服务桌面 chat_page.dart 与手机 mobile_chat_page.dart，改一次即对齐。
