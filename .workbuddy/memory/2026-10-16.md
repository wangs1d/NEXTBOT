- Release 启动坑：**必须从 exe 所在目录启动/设 WorkingDirectory**；父 shell 退出会把带管道的子进程带走（SIGPIPE），排障时用 run_in_background + 输出重定向。WorkBuddy 工具会话 shell 带 HTTP_PROXY=127.0.0.1:53079（会话级，User/Machine 级为空，用户双击不受影响），但继承该 env 启动的应用 WS 重连全被代理劫持 → 排障启动要 `env -u http_proxy -u https_proxy -u HTTP_PROXY -u HTTPS_PROXY`。
- 启动后残留两个非致命问题待查：①`[DesktopBridge] 桥接 token 与服务器 DESKTOP_BRIDGE_TOKEN 不一致`；②历史聊天图片显示碎图标（Debug 实例同会话能显示，疑似本地缓存/数据目录差异）+ 逆地理 502。
