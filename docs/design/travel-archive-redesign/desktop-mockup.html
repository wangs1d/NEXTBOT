1桌面端核心改动

  • 平铺 ListView → 双栏工作台（与图库工作台同思路）：左栏 340px 列表收纳，右栏原地预览，选中即看详情，不用跳 WebView 才知道行程里有什么
  • 详情预览三层：大封面横幅 → 元信息 chips（天数/站点/预算/进度）→ Day×Day 站点摘要网格
  • 「打开完整行程」才进应用内 WebView「行迹」面板，浏览成本前置降为零

2「时间漏斗」列表组织

  • 进行中：迷你英雄卡置顶 + 绿色描边 + 呼吸光点，当前站点直出
  • 即将出发：卡片 + 「还有 N 天」倒计时（本地计算）
  • 往期回顾：紧凑行收纳，弱化为档案视角
  • 搜索框内联 + chips 过滤（全部/即将出发/往期回顾），≤20 条本地过滤零延迟

3交互规则

  • 左栏点击 = 右栏预览切换；双击 / 「打开完整行程」= 进 WebView 详情（原行为）
  • 底部操作条：「分享码」（服务端已有）、「让 Agent 调整」（回聊天窗注入上下文）、「删除」二次确认
  • 窄窗口 < 900px 时右栏预览自动收起，退化为纯列表（手机端沿用现详情跳转）

4服务端依赖（新增，量很小）

REQUIRES BACKEND
  • DELETE /travel/plans/:planId：整体删除（当前只有条目级删除）
  • GET /travel/plans 摘要追加 progress（day/stop）与站点总数，列表与预览免二次请求
  • Day 站点摘要数据：预览打开时单拉一次 GET /travel/plans/:planId 即可（已有接口）
