行程表两档半屏（默认，地图占主）/ 全屏（上滑展开，地图压成 22% 顶部条）；下滑回半屏，再下滑可退出页面 —— 标准 bottom-sheet 手感。
行程卡白底/暗卡、圆角 14、发丝边；左 3px 类型色条（景点 22D3EE / 餐饮 F59E0B / 住宿 A78BFA / 交通 60A5FA）+ 时间 13/700 + 标题 13.5/600 + 地点 11 + 62×46 实拍缩略图 + chevron；卡距 8。
地点详情不从右侧滑栏，改为抽屉换内容：132 高封面实拍 + 类别 tag + 标题 + 事实 chip（评分/营业/距离/电话）+ 两行简介 + 「沉浸式 3D 实景」与「导航」两按钮。
地图控件左上只留「图层」（暗色/卫星/3D 视角三选，与原页面一致）；去掉桌面的 +/− 缩放与图例横排，改双指缩放；左下保留精简图例；右下 FAB「规划当日路线」。
路线结果沿用 Dart 侧 IntelligentRoutePlanner：总里程/总时长/评分 + 交通方式 chip（驾车/打车/公交/步行/骑行）+ 分段列表（含每段时长与备选建议）。
主题 / 数据深浅两套（复用桌面 --gt-* 令牌：浅色 zinc、暗色霓虹）；数据源不变，仍走 TravelPlanData.from() 的结构化 travelPlan（days/entries/lat-lng/实拍图）。
实现落点（两条路，建议 A）
A · Flutter 原生重建（推荐）：新增 lib/mobile_ui/mobile_travel_plan_page.dart；地图用 flutter_map 接服务端既有瓦片代理 /travel-basemap/fetch（零 CDN、零 WebView），行程表用 DraggableScrollableSheet；路线复用 IntelligentRoutePlanner、点位与实拍图复用 travel_map_controller / travel_image_warmer。入口在 main.dart 的 TravelPlanLauncher.setHandler 里按 Platform.isAndroid || Platform.isIOS 分流到本页（现在无条件走浏览器/Windows 窗口）。
B · 复用网页版（快，但体验打折）：给 server/web/travel-map/panel.html 加移动端断点（侧栏改抽屉、详情改底部抽屉），客户端用 webview_flutter 内嵌 —— 好处是地图/路线/3D 实景一行代码不改；代价是多一个 WebView 依赖 + 首屏要等 MapLibre。
