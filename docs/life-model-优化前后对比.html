一句话结论

旧架构强在「取回」——向量检索 + 一句话记忆，能捞回相关文本；弱在「建模」—— 回答不了「我妹妹叫什么」「上次和谁去的京都」。 本次补上 用户生活模型：把散在结构化事实 / 图式 / 经验学习 / 关系图谱里的产出 收敛为「实体–关系–时间」的一等结构，并作为第 9 条通道并入仲裁器，不新增旁路。

设计取舍与遗留

  • 收敛而非叠加：没有另起存储——6 张新表挂在同一个 openAgenticSqlite，隐私级联 purgeActor 天然覆盖。
  • 读侧单一出口：lifeModel 与其余 8 条通道一样进 arbitrateMemories，不新增旁路。
  • 热路径零新增 LLM 调用：实体物化走观察者旁路；关系里程碑检测为纯规则。
  • 遗留在后续 静态加密（设计标注为可选）本次未做；关系词自动抽取建边目前由 LLM 经 life.manage 完成，未做纯规则中文关系词解析。
